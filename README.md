# CRISPr L3 Workshop

Data quality validation workshop using the `vowl` library and data contracts.

## Contents

- `CRISPr_notebook.ipynb` — Workshop notebook covering:
  - Section 1: Demo of vowl-lens and vowl-canvas
  - Section 2: Validating HDB Resale data using the vowl library
  - Section 3: Create your own data contract and validate your own data
- `hdb_resale_data_contract.yaml` — Data contract for HDB resale prices
- `hdb_resale_golden.csv` — Golden dataset for contract generation
- `hdb_resale_with_errors.csv` — Dataset with intentional errors for validation
